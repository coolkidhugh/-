# 大橙子日常带娃指南

> 来源：老婆写的带娃笔记。晚饭由老婆下班回来做，其余时段按本流程执行。

## 物品位置速查

| 物品 | 位置 |
|------|------|
| 奶瓶（带吸管 + 重力球） | 消毒柜，或消毒柜旁边的收纳盒 |
| 新拉拉裤 | 房间 |
| 围兜 | 消毒柜附近 |
| 擦脸毛巾 / 湿巾 | 毛巾架 |
| 浴室擦身布 | 浴室门后 |
| 辅食碗 + 勺子 | 常规餐具区 |
| 水煮蛋 | 蒸箱里 |
| 预切蔬菜 | 冰箱 |
| 水杯、纸巾、备用拉拉裤、雨伞 | 婴儿车下方 |

---

## 早上（7:00–8:00 起床）

按顺序执行，不要跳步。

### 1. 喝奶

1. 取带吸管和重力球的奶瓶
2. **先倒水**，水温 **40–45°C**
3. 配方：**180ml 水 + 6 平勺** 奶粉
   - 每勺在奶粉罐边缘刮平
   - 一勺一勺加，不要一次倒完
4. 盖紧瓶盖，摇匀

### 2. 换拉拉裤

- 喝完奶、**大便后**换（通常早上会拉）
- 立刻带去浴室，**温水**洗干净
- 用浴室门后的布擦干
- 换上新拉拉裤（在房间取）

### 3. 吃早饭

- 食物：蒸箱里的**水煮蛋**
- 戴上围兜
- 放入辅食碗，用勺子**切成小块**，**一口一口喂**
- 吃的过程中或吃完喝几口水，**防呛**

### 4. 洗脸洗手 → 换衣服 → 出门

- 用湿巾或毛巾架上的毛巾洗脸
- 穿短袖短裤，或长裤；**穿袜子防蚊**
- 带水杯出门
- 婴儿车下方备：纸巾、拉拉裤、雨伞

---

## 中午（11:00–12:00 午睡）

### 睡前喝奶（视情况）

- 上午出门回来**还没睡着** → 冲奶：**150ml 水 + 5 平勺** 奶粉
- 如果在户外已经睡着了 → **不要喂奶**

### 午睡

- 通常 **11:00–12:00** 开始
- 方式：竖抱在肩上，边走边**拍屁股**哄睡
- **提前**把空调调到 **24.5°C**，房间不要太热
- 脱掉外裤，衣服拉好，**肚子不要露出来**
- 一般睡 **1–2 小时**

### 做午饭（趁宝宝睡着）

1. 冰箱取预切蔬菜 + 米饭，放入**小陶瓷蒸碗**
2. 碗里加饮用水，**略高于食材**
3. 蒸箱底座加水至刻度线
4. 陶瓷碗盖盖，再盖塑料蒸箱盖
5. 选 **「蒸煮」** 功能；完成后自动切到 **「保温」**

### 换拉拉裤（视情况）

- 上午回家可能需要换；也可能睡醒后换
- **先换拉拉裤，再喂午饭**

### 喂午饭

1. 坐**餐椅**
2. 湿巾擦手，戴围兜（消毒柜附近）
3. **必须等饭凉了再喂**
4. 先在自己手上试一小口：检查**烫不烫、饭熟没熟**

---

## 下午

### 出门

- 看天气和情况，流程同**早上出门**

### 下午觉（视情况）

| 情况 | 处理 |
|------|------|
| 早上 7 点或更早起床，中午 10 点多就睡了 | 下午出门回来 **4 点左右** 可能要再睡 **1 小时** |
| 早上 8 点后正常起床，中午 12 点多睡，睡到 2 点多 | 下午**大概率不睡** |

### 下午水果

- 可以吃**香蕉**，扒皮直接给他啃

---

## 晚饭

**等老婆下班回来做**，不需要你准备。

---

## 决策树（快速判断）

```
起床 → 喝奶(180ml/6勺) → 大便? → 换拉拉裤+清洗 → 吃早饭(水煮蛋) → 出门

回家 → 已睡着? ─是→ 直接午睡流程
              └否→ 睡前奶(150ml/5勺) → 午睡

睡醒 → 换拉拉裤? → 喂午饭(试温!) → 下午出门 → 4点要睡? → 水果(香蕉)

晚饭 → 等老婆
```

## 给 Agent 的使用说明

- 用户问「明天怎么带」「现在该干嘛」「大橙子下一步做什么」时，对照当前时间段和上面决策树给出**下一步具体操作**
- 提醒关键安全点：**试温再喂饭**、**防呛喝水**、**空调 24.5°C**、**户外睡着不喂奶**
- 用户慌乱时，优先给出**当前只需做的一件事**，不要一次倾倒全部流程
